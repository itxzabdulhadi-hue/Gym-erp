# API Reference

> Generated by `npm run docs` from the live Express route table. Do not edit by hand.

Base path: `/api`. 168 endpoints.

## Conventions

- **Auth** - `Authorization: Bearer <accessToken>` or the `erp_at` cookie set at login.
- **Tenant** - taken from the token. A platform admin may pass `X-Tenant-Id` to act on another tenant; every other caller is rejected.
- **Envelope** - single resources come back as `{ "data": ... }`, lists as `{ "data": [...], "meta": { "page", "limit", "total", "totalPages" } }`.
- **Errors** - `{ "error": { "code", "message", "details?" } }`. Codes in use: `VALIDATION_ERROR` (422), `UNAUTHORIZED` (401), `FORBIDDEN` (403), `MODULE_DISABLED` (403), `CONFLICT` (409), `NOT_FOUND` (404), `RATE_LIMITED` (429), `INTERNAL_ERROR` (500).
- **Permissions** - `<module>.<action>` keys from `shared/src/modules.js`. A caller needs every key listed for an endpoint.
- **Modules** - an endpoint whose module is disabled for the tenant returns 403 `MODULE_DISABLED`, regardless of permissions.
